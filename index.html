    Conexión con la nube sin configurar
    Sin configurar, el historial vive solo en este navegador. Con un proyecto de Supabase detrás, los embarques se comparten entre quienes tengan cuenta.
    La clave publicable es pública por diseño: lo que protege los datos son las políticas RLS —que exigen usuario autenticado— y la sesión de cada persona. El SQL está en supabase/esquema.sql del repositorio.
    Sirve como la muestre el panel: si trae /rest/v1 al final, se recorta solo.
    La de arriba en API Keys, la que dice «can be safely shared publicly». No la secreta (sb_secret_…): esa salta las políticas RLS y en un sitio público le da acceso de administrador a cualquiera.
    Para que el enlace funcione para todos

    Esto vale solo para este navegador. Quien abra el enlace sin haberlo configurado no ve proyecto, no se le pide cuenta y la app aparece vacía. Pega este bloque en js/config.js del repositorio y vuelve a publicar: entonces la configuración viaja con el sitio y cada persona solo entra con su cuenta.

    Es una exposición, no un pronóstico. Dice cuánto hay en juego si el plan se cumple tal cual, con el rate mediano de la temporada y un descuento fijo por recalada.
